HyperVoice Code privacy policy
Last updated: 24 November 2026

HyperVoice Code is a desktop workspace for Claude Code and Codex, made by Chris Cousens (contact: support@hypervoice.app).

What the app reads
HyperVoice Code reads the session files that Claude Code and Codex save on your PC (in your user folder, under .claude and .codex) so it can show your conversations, and it checks whether the HyperVoice app is installed. All of this happens on your PC.

What the app sends
HyperVoice Code has no account, no analytics and no tracking. It does not send your conversations, your files or any personal information to us or to anyone else. When you open "What's new", it may download the app's public release notes from GitHub. Updates for the Microsoft Store version come from the Microsoft Store.

Claude Code and Codex
The terminal inside HyperVoice Code runs Claude Code (from Anthropic) or Codex (from OpenAI), separate programs that you install and sign in to yourself. What they send to Anthropic or OpenAI is covered by those companies' terms and privacy policies, not this one.

Links
If you click a link in the app (for example to hypervoice.app or the Microsoft Store), your browser opens that site and that site's own privacy policy applies.

Changes
If this policy changes, the new version will be published here with a new date.
